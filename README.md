## 🎯 Learning Objectives
- Understand hash function design and collision resolution
- Implement HashMap and HashSet from scratch
- Apply frequency counting patterns to reduce O(n²) to O(n)
- Solve Two-Sum, Group Anagrams, Longest Subarray problems
- Design custom hashable objects

## 📌 Topics Covered
| # | Topic | Pattern | Freq |
|---|-------|---------|------|
| 1 | Frequency Count | Counter, defaultdict | ⭐⭐⭐⭐⭐ |
| 2 | Two Sum Variants | complement lookup | ⭐⭐⭐⭐⭐ |
| 3 | Group Anagrams | sorted tuple key | ⭐⭐⭐⭐⭐ |

## 📋 Problem Statements
### P1 — Two Sum: `[2,7,11,15],target=9→[0,1]`
### P2 — Group Anagrams: `["eat","tea","tan","ate"]→groups`
### P3 — Subarray Sum K: `[1,1,1],k=2→2` subarrays
### P4 — Longest Unique Window: `"abcabcbb"→3`
### P5 — Top K Frequent: `[1,1,1,2,2,3],k=2→[1,2]`
### P6 — 4Sum Count: Count tuples from 4 arrays summing to 0
